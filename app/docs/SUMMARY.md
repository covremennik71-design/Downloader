# Сводка проекта Downloader

Этот документ — краткая актуальная сводка. Он заменяет прежние утверждения о том, что проект полностью упакован в автономный EXE.

## Состав

Проект содержит две версии приложения:

1. **Tauri:** frontend в `app/src`, Rust backend в `app/src-tauri`, запуск системного Python/yt-dlp.
2. **Standalone Python:** `downloader.py`, CustomTkinter GUI и общая Python-валидация URL в `url_utils.py`.

## Основные функции

- Нормализация и проверка YouTube URL.
- Получение метаданных и списка доступных качеств.
- Загрузка через yt-dlp.
- Прогресс и отмена загрузки.
- Выбор каталога сохранения.
- FFmpeg для объединения видео/аудио и преобразования в MP3.

## Запуск

Из корня репозитория:

```bat
python -m pip install -r requirements.txt
run.bat
```

Tauri-разработка:

```bat
dev.bat
```

Tauri EXE:

```bat
build.bat
```

Результат сборки — `YouTube Downloader.exe` в корне репозитория.

## Ограничения

- Tauri EXE не является автономным Python bundle: на целевой машине нужны системный Python и `yt-dlp`.
- FFmpeg требуется для объединения отдельных потоков и MP3-конвертации.
- CI проверяет синтаксис Python, unit tests, JavaScript syntax и компиляцию Rust/Tauri. Это не заменяет ручной Windows GUI smoke test и реальную загрузку.
- YouTube может менять сетевые и player API; для проверки реальных загрузок нужна актуальная версия yt-dlp и end-to-end тестирование.
