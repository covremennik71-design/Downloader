## 🏗️ Архитектура

```
Frontend (HTML/CSS/JS)
    ↓ Tauri IPC
Tauri Backend (Rust)
    ↓ Subprocess
Python Backend (yt-dlp + FFmpeg)
```

**Поток данных:**
1. Пользователь вводит URL
2. Frontend → Tauri → Python (получение информации)
3. Python → Tauri → Frontend (отправка данных)
4. Frontend отображает видеокарточку
5. Пользователь выбирает качество
6. Frontend → Tauri → Python (загрузка)
7. Python отправляет прогресс через stdout
8. Tauri передаёт прогресс в Frontend
9. Frontend обновляет UI в реальном времени
