## 📋 Найденные проблемы и решения

### Проблема 1: Несовпадение Tauri features и allowlist ❌ → ✅

**Симптом:**
```
The `tauri` dependency features on the `Cargo.toml` file does not match the allowlist defined under `tauri.conf.json`.
Please run `tauri dev` or `tauri build` or remove the `path-all, dialog-all, fs-all` features.
```

**Причина:**
- В `Cargo.toml` были включены features: `path-all`, `shell-all`, `dialog-all`, `fs-all`
- В `tauri.conf.json` в allowlist были указаны только `shell` permissions
- Tauri требует строгого соответствия между features и allowlist

**Решение:**
Обновлён файл `src-tauri/tauri.conf.json`:

```json
"allowlist": {
  "all": false,
  "shell": {
    "all": true,
    "open": true,
    "sidecar": true,
    "execute": true,
    "scope": [
      {
        "name": "python",
        "cmd": "python",
        "args": true
      }
    ]
  },
  "path": {
    "all": true
  },
  "dialog": {
    "all": true,
    "open": true,
    "save": true
  },
  "fs": {
    "all": true,
    "scope": ["**"]
  }
}
```

**Результат:** ✅ Все features теперь соответствуют allowlist

### Проблема 2: Предупреждения pip о битых пакетах ⚠️ → ✅

**Симптом:**
```
WARNING: Ignoring invalid distribution ~t-dlp
```

**Причина:**
- В папке `site-packages` остались битые директории от неудачных установок
- pip не может их корректно обработать и выдаёт предупреждения

**Решение:**
Обновлён файл `build.bat` - добавлена агрессивная очистка:

```batch
:: Clean up ALL broken pip distributions to remove warnings
echo Cleaning broken pip packages...
for /d %%i in ("%LOCALAPPDATA%\Programs\Python\Python314\Lib\site-packages\~*") do (
    echo Removing broken package: %%~nxi
    rmdir /s /q "%%i" 2>nul
)
for /d %%i in ("%LOCALAPPDATA%\Programs\Python\Python314\Lib\site-packages\*.dist-info") do (
    if exist "%%i\~" (
        echo Removing broken dist-info: %%~nxi
        rmdir /s /q "%%i" 2>nul
    )
)
:: Upgrade pip first to avoid warnings
python -m pip install --upgrade pip --quiet
```

**Результат:** ✅ Все битые пакеты удаляются автоматически

## 🔧 Технические детали

### Tauri Commands

1. **`get_video_info(url: String)`**
   - Получает информацию о видео через yt-dlp
   - Возвращает JSON с title, thumbnail, duration, formats
   - Форматы сортируются по высоте (144p - 4K)

2. **`start_download(url, quality, format_type, save_path)`**
   - Запускает загрузку видео/аудио
   - Передаёт прогресс через Tauri events
   - Поддерживает отмену

3. **`select_folder()`**
   - Открывает диалог выбора папки
   - Возвращает выбранный путь

4. **`cancel_download()`**
   - Отменяет текущую загрузку

### Python Scripts (встроенные в Rust)

**yt_info.py:**
- Извлекает информацию о видео
- Парсит доступные форматы
- Возвращает JSON

**yt_download.py:**
- Скачивает видео/аудио
- Ищет FFmpeg автоматически
- Отправляет прогресс через stdout
- Поддерживает конвертацию в MP4/MP3

## 🐛 Известные ограничения

1. **FFmpeg не включён в EXE**
   - Пользователь должен установить FFmpeg отдельно
   - Или разместить в папке `ffmpeg/bin/`
